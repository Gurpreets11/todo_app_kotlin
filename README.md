# ToDo App

A simple and efficient task management app built with Kotlin for Android. The app allows users to add, edit, and delete tasks, with features like categorizing and setting due dates. Tasks are securely stored in a local database, ensuring data persistence even after the app is closed.

## Features
- Add, edit, and delete tasks.
- Organize tasks into categories.
- Set and view due dates for tasks.
- Local database storage for task persistence.
- Clean and intuitive user interface.

## Technologies Used
- Kotlin
- Android Architecture Components (Room for local database)
- Jetpack Libraries
- MVVM Architecture Pattern

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Gurpreets11/todo_app_kotlin.git
   ```
2. Open the project in Android Studio.

3. Build and run the app on your emulator or device.
